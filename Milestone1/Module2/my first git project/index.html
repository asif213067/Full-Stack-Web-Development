One time when initailiation project

git init

One time connect local project to remote github website

git remote add origin https://github.com/asif213067/my-first-git-project.git

Every time to add everything

All file: git add .

Single file: git add file_name

Every time to push code

First push: git push -u origin main

Leter push: git push

Git Commands

| Command | Function |
| ------------------------- | -------------------------------- |
| `git init` | Initialize a repository |
| `git status` | Show repository status |
| `git add .` | Stage all changes |
| `git commit -m "message"` | Save staged changes |
| `git log` | Show commit history |
| `git branch` | List branches |
| `git switch` | Switch branches |
| `git remote -v` | Show remote repositories |
| `git push` | Upload changes to GitHub |
| `git pull` | Download and merge changes |
| `git fetch` | Download changes without merging |
| `git clone` | Copy a repository from GitHub |
